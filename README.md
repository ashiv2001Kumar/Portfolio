# Portfolio

Personal portfolio of Ashiv Kumar, a full stack developer. Built with Next.js, React and Tailwind CSS, with dark and light themes and an animated hero scene.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Editing content

All text (bio, skills, projects, experience, contact links) lives in `lib/data.ts`.
